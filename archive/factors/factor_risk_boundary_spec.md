## 一、通用12因子（跨品种）

### F01: daily_return

| 项目 | 内容 |
|------|------|
| **公式** | `daily_return = P_t / P_{t-1} - 1` |
| **风险等级** | 🟢 低 |
| **适用品种** | 全部10品种: AL, CU, PB, LC, FU, BU, ZN, NI, SN, SI |
| **适用区制** | 全部区制: TYPE_S, TYPE_C, MIXED, CRISIS |
| **失效场景** | 流动性枯竭(成交量<MA20×阈值×0.5)时价格跳空失真；CRISIS区制下IC可能翻转 |
| **参数敏感点** | 无参数(直接计算日收益率) |
| **可容忍漂移** | IC衰减<10%年化；连续3日IC反向触发预警 |
| **预警条件** | 连续3日IC反向 → 黄色预警；连续5日IC反向 → 红色预警+因子降级 |

### F02: return_5d

| 项目 | 内容 |
|------|------|
| **公式** | `return_5d = P_t / P_{t-5} - 1` |
| **风险等级** | 🟡 中 |
| **适用品种** | 全部10品种(通用) |
| **适用区制** | TYPE_S(动量驱动), MIXED |
| **失效场景** | 5日窗口内存在政策突变/极端事件(SI 2023-11连续5日跌停)；IC在商品供给冲击周期下可能翻转(见walkforward窗口20: IC从-0.040翻转为-0.186) |
| **参数敏感点** | 窗口长度5d(固定)；NI/SI品种事件密集可能需要更长窗口 |
| **可容忍漂移** | IC衰减<15%年化；滚动IC均值<0.005持续10日触发降级 |
| **预警条件** | 滚动IC均值<0.005持续10日 → 红色预警+因子降级 |
| **LOO贡献** | +4.68pp (10因子池第4名) |

### F05: momentum_signal

| 项目 | 内容 |
|------|------|
| **公式** | `momentum_signal = MA(5) - MA(20)` |
| **风险等级** | 🔴 高 |

| **适用区制** | TYPE_S(趋势市), MIXED |

### F13: carry_signal

| 项目 | 内容 |
|------|------|
| **公式** | `carry = 近月-远月 - (仓储费+保险费+利率) × 期限` |
